# Дашборд чистки логотипов

## Запуск
1. `python -m venv venv && . venv/bin/activate && pip install -r requirements.txt`
2. Положить PDF-макеты в `input/`
3. `python src/server.py`  →  открыть http://localhost:8000

## Процесс
- Слева выбрать фигуру.
- Мышью нарисовать рамку(и) на логотипах (грудь, кепка, телефон, табличка — по ОБЕИМ панелям).
- «🧽 Вычистить лого» → удаляются вектор-объекты в рамках (крупные формы фигуры защищены),
  показывается результат + мини-валидация (размер/вектор/исходник).
- «До/После» — сравнить. «✗ Сбросить» — переделать.
- «✓ Подтвердить → в чистые» — после твоей проверки файл уезжает в `clean/`.

## Папки
- input/  — исходники (не изменяются)
- output/ — очищенные, ждут подтверждения
- clean/  — подтверждённые чистые фигуры
